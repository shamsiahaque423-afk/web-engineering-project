Skill Linker


Overview:

Skill Linker is a web-based platform designed to connect individuals who want to learn new skills with people who are willing to teach or share their expertise. The system helps users discover skills, find suitable mentors or learners, and build a collaborative learning community.

Features:

•	User Registration and Login
•	Secure Authentication System
•	User Profile Management
•	Skill Posting and Management
•	Search Skills and Users
•	Mentor and Learner Matching
•	Skill Request System
•	Dashboard for Managing Activities
•	Database-Driven Data Storage
•	Responsive User Interface

Installation Guide:

    Prerequisites:

•	XAMPP
•	PHP 8+
•	MySQL
•	Web Browser

    Steps:

1. Clone the repository:

git clone https://github.com/your-username/Skill-Linker.git

2. Move the project folder to:

htdocs/

3. Start Apache and MySQL from XAMPP.

4. Create a new database:

skill_linker

5. Import the SQL file:

database/skill_linker.sql

6. Open your browser and visit:

http://localhost/Skill-Linker/


   Database:

The project uses MySQL to store:

•	User Information
•	Skills
•	Learning Requests
•	Messages
•	User Profiles
